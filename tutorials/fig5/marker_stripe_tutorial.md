# Identifying Marker Stripes with scStripe

## Overview

This tutorial identifies cell-type-specific marker stripes from the per-cell stripe-score matrix generated by scStripe.

## Input

1. `stripe_score_matrix.tsv`: rows are stripes and columns are cells.
2. `cell_metadata.tsv`: rows are cells and the `cell_type` column contains cell-type labels.


Example `stripe_score_matrix.tsv`:

```text
stripe_id                    cell_001  cell_002  cell_003
chr1:100000-500000:3prime      1.25      0.82      2.31
chr2:700000-920000:5prime      0.91      1.73      1.05
```

Example `cell_metadata.tsv`:

```text
cell_id    cell_type
cell_001   early_neurons
cell_002   blood
cell_003   early_neurons
```

## Identify marker stripes

```python
import scanpy as sc
import pandas as pd
import numpy as np

# Load data
scores = pd.read_csv(
    "stripe_score_matrix.tsv",
    sep="\t",
    index_col=0,
)

metadata = pd.read_csv(
    "cell_metadata.tsv",
    sep="\t",
    index_col=0,
)

# Match cells in the two files
common_cells = scores.columns[scores.columns.isin(metadata.index)]
scores = scores.loc[:, common_cells]
metadata = metadata.loc[common_cells].copy()
metadata["cell_type"] = metadata["cell_type"].astype("category")

# A stripe score of 1 indicates no enrichment over the flanking regions
scores = scores.mask(scores == 1, 0)

# Create an AnnData object: cells x stripes
adata = sc.AnnData(
    X=scores.T.to_numpy(dtype=float),
    obs=metadata,
)
adata.obs_names = scores.columns.astype(str)
adata.var_names = scores.index.astype(str)
adata.var_names_make_unique()

# Apply the filtering thresholds used in the article
cell_mask = np.count_nonzero(adata.X, axis=1) >= 3000
adata = adata[cell_mask].copy()

stripe_mask = np.count_nonzero(adata.X, axis=0) >= 300
adata = adata[:, stripe_mask].copy()

# Normalize the continuous stripe scores
sc.pp.normalize_total(adata, target_sum=1e4)
sc.pp.log1p(adata)

# Compare each cell type with the remaining cells
sc.tl.rank_genes_groups(
    adata,
    groupby="cell_type",
    method="t-test",
    only_positive=True,
    use_raw=False,
)

# Retain significant marker stripes
markers = sc.get.rank_genes_groups_df(adata, group=None)
markers = markers[
    (markers["pvals_adj"] < 0.05)
    & (markers["logfoldchanges"] > 0)
].rename(columns={
    "names": "stripe_id",
    "group": "cell_type",
})

markers.to_csv("marker_stripes.tsv", sep="\t", index=False)
```

## Output

- `marker_stripes.tsv`: all significant marker stripes.

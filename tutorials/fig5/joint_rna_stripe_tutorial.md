# Joint Embedding of RNA and Stripe Scores

## Overview

This tutorial integrates per-cell stripe scores with matched scRNA-seq profiles from the same cells. It generates an RNA-only embedding and a joint RNA-plus-stripe embedding.

## Input

### 1. RNA expression matrix

Rows are genes, columns are cells, and values are raw RNA counts.

Example `gene_expression_matrix.tsv`:

```text
gene_id    cell_001  cell_002  cell_003
Sox2          3         0         5
Otx2          0         2         4
```

### 2. Per-cell stripe-score matrix

Rows are stripes, columns are cells, and values are per-cell stripe scores generated by scStripe.

Example `stripe_score_matrix.tsv`:

```text
stripe_id                    cell_001  cell_002  cell_003
chr1:100000-500000:3prime      1.25      0.82      2.31
chr2:700000-920000:5prime      0.91      1.73      1.05
```

### 3. Cell metadata

Example `cell_metadata.tsv`:

```text
cell_id    cell_type
cell_001   early_neurons
cell_002   blood
cell_003   early_neurons
```


## Joint analysis

```python
import numpy as np
import pandas as pd
import scanpy as sc

rna_matrix = pd.read_csv(
    "gene_expression_matrix.tsv",
    sep="\t",
    index_col=0,
).astype(float)

stripe_matrix = pd.read_csv(
    "stripe_score_matrix.tsv",
    sep="\t",
    index_col=0,
).astype(float)

metadata = pd.read_csv(
    "cell_metadata.tsv",
    sep="\t",
    index_col=0,
)

# Match cells across the three files while preserving RNA column order
common_cells = rna_matrix.columns[
    rna_matrix.columns.isin(stripe_matrix.columns)
    & rna_matrix.columns.isin(metadata.index)
]

rna_matrix = rna_matrix.loc[:, common_cells]
stripe_matrix = stripe_matrix.loc[:, common_cells]
metadata = metadata.loc[common_cells].copy()
metadata["cell_type"] = metadata["cell_type"].astype("category")

# A stripe score of 1 indicates no enrichment over the flanking regions
stripe_matrix = stripe_matrix.mask(stripe_matrix == 1, 0)


def preprocess(feature_matrix, metadata):
    adata = sc.AnnData(
        X=feature_matrix.T.to_numpy(dtype=float),
        obs=metadata.copy(),
    )
    adata.obs_names = feature_matrix.columns.astype(str)
    adata.var_names = feature_matrix.index.astype(str)
    adata.var_names_make_unique()

    # Filtering thresholds used in the article
    sc.pp.filter_cells(adata, min_genes=2500)
    sc.pp.filter_genes(adata, min_cells=300)

    sc.pp.normalize_total(adata, target_sum=1e4)
    sc.pp.log1p(adata)

    sc.pp.highly_variable_genes(
        adata,
        n_top_genes=min(5000, adata.n_vars),
        flavor="seurat",
        subset=True,
    )

    sc.pp.scale(adata, max_value=10)
    sc.tl.pca(adata, n_comps=35, svd_solver="arpack")

    return adata


stripe_adata = preprocess(stripe_matrix, metadata)
rna_adata = preprocess(rna_matrix, metadata)

# Keep cells passing the filtering criteria in both modalities
shared_cells = rna_adata.obs_names.intersection(stripe_adata.obs_names)
rna_adata = rna_adata[shared_cells].copy()
stripe_adata = stripe_adata[shared_cells].copy()

# RNA-only representation: first 35 RNA PCs
rna_embedding = rna_adata.obsm["X_pca"][:, :35]

# Joint representation: 20 RNA PCs + 15 stripe PCs
joint_embedding = np.concatenate(
    [
        rna_adata.obsm["X_pca"][:, :20],
        stripe_adata.obsm["X_pca"][:, :15],
    ],
    axis=1,
)


def run_umap(embedding, metadata):
    adata = sc.AnnData(X=embedding)
    adata.obs = metadata.copy()

    sc.pp.neighbors(adata, n_neighbors=35, use_rep="X")
    sc.tl.louvain(adata, resolution=1.5, key_added="cluster")
    sc.tl.umap(adata)

    return adata


rna_result = run_umap(
    rna_embedding,
    rna_adata.obs,
)

joint_result = run_umap(
    joint_embedding,
    rna_adata.obs,
)

sc.pl.umap(rna_result, color="cell_type", title="RNA only")
sc.pl.umap(joint_result, color="cell_type", title="RNA + stripe")
```

## Output

The analysis produces two 35-dimensional representations:

- RNA only: the first 35 RNA principal components;
- RNA + stripe: the first 20 RNA principal components combined with the first 15 stripe principal components.

Both representations are analyzed using a 35-nearest-neighbor graph, Louvain clustering at resolution 1.5, and UMAP visualization.

# UMAP Analysis of Per-Cell Stripe Scores

## Overview

This tutorial uses genome-wide per-cell stripe scores to visualize biological variation among cells.

## Input

### 1. Per-cell stripe-score matrix

Rows are stripes, columns are cells, and values are per-cell stripe scores generated by scStripe.

Example `stripe_score_matrix.tsv`:

```text
stripe_id                    cell_001  cell_002  cell_003
chr1:100000-500000:3prime      1.25      0.82      2.31
chr2:700000-920000:5prime      0.91      1.73      1.05
```

### 2. Cell metadata

The metadata may contain cell type, major cell population, cell-cycle phase, and developmental stage.

Example `cell_metadata.tsv`:

```text
cell_id    cell_type        main_population    cell_cycle    stage
cell_001   early_neurons    embryonic_tissues  G1            E85
cell_002   blood            blood               G0            E95
cell_003   early_neurons    embryonic_tissues  Early-S       E85
```


## Stripe-score analysis

```python
import numpy as np
import pandas as pd
import scanpy as sc

scores = pd.read_csv(
    "stripe_score_matrix.tsv",
    sep="\t",
    index_col=0,
)

metadata = pd.read_csv(
    "cell_metadata.tsv",
    sep="\t",
    index_col=0,
)

# Match cells while preserving matrix column order
common_cells = scores.columns[scores.columns.isin(metadata.index)]
scores = scores.loc[:, common_cells]
metadata = metadata.loc[common_cells].copy()

# A stripe score of 1 indicates no enrichment over the flanking regions
scores = scores.mask(scores == 1, 0)

# Create an AnnData object: cells x stripes
adata = sc.AnnData(
    X=scores.T.to_numpy(dtype=float),
    obs=metadata,
)
adata.obs_names = scores.columns.astype(str)
adata.var_names = scores.index.astype(str)
adata.var_names_make_unique()

# Filtering thresholds used in the article
cell_mask = np.count_nonzero(adata.X, axis=1) >= 3000
adata = adata[cell_mask].copy()

stripe_mask = np.count_nonzero(adata.X, axis=0) >= 300
adata = adata[:, stripe_mask].copy()

# Normalize, log-transform, and scale
sc.pp.normalize_total(adata, target_sum=1e4)
sc.pp.log1p(adata)
sc.pp.scale(adata, max_value=10)

# PCA, 35-nearest-neighbor graph, Louvain clustering, and UMAP
sc.tl.pca(adata, n_comps=20, svd_solver="arpack")
sc.pp.neighbors(adata, n_neighbors=35, n_pcs=20)
sc.tl.louvain(
    adata,
    resolution=1.0,
    random_state=0,
    key_added="cluster",
)
sc.tl.umap(adata, random_state=0)

# Visualize different biological annotations on the same embedding
sc.pl.umap(adata, color="main_population")
sc.pl.umap(adata, color="cell_type")
sc.pl.umap(adata, color="cell_cycle")
sc.pl.umap(adata, color="stage")
sc.pl.umap(adata, color="cluster")

# Save UMAP coordinates and annotations
result = adata.obs.copy()
result[["UMAP_1", "UMAP_2"]] = adata.obsm["X_umap"]
result.to_csv("stripe_score_umap.tsv", sep="\t")
```

## Output

The analysis produces a UMAP embedding based only on genome-wide per-cell stripe scores. The same embedding can be colored by cell type, major cell population, cell-cycle phase, developmental stage, or Louvain cluster.

The output file `stripe_score_umap.tsv` contains the UMAP coordinates and metadata for every retained cell.
